Cemetery Fieldbook v7 TEST — Smart Backup Retention

Upload index.html to the GitHub cemetery-fieldbook/test folder only.

New: preview which app-created cloud backups would be retained or eligible for cleanup; opt-in automatic retention after a NEW verified backup; Protect button permanently renames backups to prevent cleanup; manually uploaded backup filenames are excluded.

Default: automatic retention OFF. No backups are removed by installing this update or previewing retention.

Retention: newest 10 app-generated backups, plus one per week (last four weeks), and one per calendar month (last six months). Overlap is allowed. OneDrive Recycle Bin may still use storage.

Before enabling cleanup: review the exact preview list, and keep a separate downloaded backup.
