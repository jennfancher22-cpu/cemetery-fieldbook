3 · Backup and restore Protect and transfer your data

Backups and field notes

Upgrading? Keep your v6.1 backup safe. This LIVE release opens your existing local records using the same storage keys. Do not restore a backup unless recovery is needed; restoring replaces current data.

Your edits and attached photos are kept on this device in this browser. Export a backup after each cemetery trip. The new full backup includes the original burial list, photos, notes, and change history. You can restore it here or on a different device.

Important: This app stores records privately on this device and is not synced. Browser storage may be erased, especially if you clear browsing data or open the file in a different app. Keep backups. Nearby search calculates straight-line miles for cemeteries with verified coordinates; it is not driving distance. GPS requires a secure HTTPS installation and may be blocked when this file is opened from Downloads. Automatic synchronization is not included.

Start over / reset Fieldbook data

Use this only when you want an empty Fieldbook before a fresh GEDCOM import. This erases this browser's LIVE burial entries, edits, discoveries, photographs, visit statuses, change history, saved cemetery coordinates, Home Person, and GEDCOM directory. It does not delete your downloaded backups or the app on GitHub. It does not erase TEST Fieldbook records.

Refresh relationship links

Update the relationship directory from your GEDCOM without changing burial records, field notes, or photographs.

For marriage relationships, reload your GEDCOM directory once to include spouse links. Existing burials, edits, and photos are preserved.

Detailed relationship verification

Compare a few known relatives with your family tree before applying calculations to thousands of burials. Uses the Home Person and parent-child links saved from your GEDCOM. Calculated values also appear in burial entries and their edit forms where fields are blank. These are GEDCOM-derived suggestions; the underlying stored records and manual notes are not changed automatically.

Restore missing Find a Grave links

If an imported person is missing a memorial link, select the same GEDCOM you imported. Fieldbook will match people by GEDCOM ID and fill only empty Find a Grave URL fields. Your photographs, notes, relationships, and visit records will not be replaced.
